# 🌍 Global Debt Analysis Project

## 📌 Project Overview
The **Global Debt Analysis Project** is a Data Analytics and Visualization project developed using **Python, Excel, Jupyter Notebook, and Power BI**. The main goal of this project is to analyze debt data of different countries over multiple years and generate meaningful insights through charts, trends, and dashboards.

This project helps in understanding:
- Countries with the highest debt
- Global debt trends over time
- High-risk countries based on debt values
- Country-wise comparison of debt
- Financial growth and risk patterns

The project combines programming, data analysis, and dashboard visualization techniques to transform raw data into business insights.

# 🔥 Difference Between Python and Jupyter Notebook

| Python (.py) | Jupyter Notebook (.ipynb) |
|---|---|
| Runs complete script | Runs code cell-by-cell |
| Used for automation | Used for analysis |
| Console output | Interactive output |
| Best for software development | Best for visualization |
